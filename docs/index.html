02.2 · built for agents

a keyboard tool with a machine-readable contract.

03 · install

one command. ready for the next word.

npx github:aPoWall/language-relay install
  1. run the command above. it builds the app from source and installs it into ~/Applications with a launch agent.
  2. approve accessibility access when macos asks. the app needs it to repair the focused field.
  3. type ghbdtn anywhere and tap double shift. the menu bar mark shows the active alphabet.

04 · privacy · local by design

your text stays on your mac.
