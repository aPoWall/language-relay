02 / gestures

Clean by design.

Double Shift or a clean standalone Option tap repairs text. Option with Command, a letter, or any other modifier stays untouched.

03 / local

No text log.

The transient buffer lives in memory, clears on context changes and Secure Input, and never reaches a server. Writable fields are read back before Type Relay reports success.

04 / feedback

Micro-SFX.

Pulse, Relay, Scan, and Flux – four 110–200 ms generated glitch cues with four volume presets.
