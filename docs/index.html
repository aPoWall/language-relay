01 / signal

Small gesture. verified result.

repair · word / phrase

Double Shift or a clean Option tap repairs the last language run. No visible selection. No duplicate paste.

switch · current layout

One state, one switch. Caps / Hyper can stay in Karabiner; Language Relay reads the final event.

local · no text log

Conversion is derived from installed macOS layouts. The transient buffer stays in memory and clears on context change.

caramba-aware

Caramba adds auto-switching, typo repair, ё rules, exceptions, custom sounds and plain paste. It uses the same Shift / Option gestures, so when Caramba runs it owns those triggers; Language Relay keeps menu, Caps / Hyper and CLI access.

02 / agents
