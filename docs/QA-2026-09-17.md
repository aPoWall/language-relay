## Observation: escape through the driver

`axdrive key --window 9516 --keys esc` posts the key to the process, and the non-activating popover does not
take it, because the panel is not the key window while the user's app stays frontmost. The escape path
itself is covered offscreen (`--ui-self-test`, `closeReasons`) and by hand when the panel is opened from the
menu bar. For stand runs the closing route is `--testbed hide`, which reaches the same `close(reason:)`.

## Live layout switch (wave 9 § D)

`--live-json --seconds N` watches the system input source and prints every switch it saw, with the second it
happened at. It reads only: no window, no key, no layout change, no focus change, so it runs while the Mac
is being worked on.

Runs of build 22 and build 23:

| run | samples | switches | reading |
|-----|---------|----------|---------|
| 600 s, build 22, 00:03 to 00:13 | 2338 | 0 | the machine was idle, nobody switched a layout |
| 8 s, build 22, two switches fired through the product's own `--switch` | 32 | 0 | wrong: the watch kept the source it read at launch |
| 8 s, build 23, the same two switches | 31 | 2 | `RussianWin → US` at 2.36 s, `US → RussianWin` at 4.43 s |

The second row is the defect the check found: a process that only sleeps never receives the input source
notification, so `TISCopyCurrentKeyboardInputSource` answers with the value it had at launch. Build 23 turns
the run loop between samples (`CFRunLoopRunInMode(.defaultMode, 0.25, false)`) and reads both switches.

The two switches were fired only because the machine was idle for 910 s (`ioreg -c IOHIDSystem`,
`HIDIdleTime`), each one through the product's own route, and the input source was read back as
`com.apple.keylayout.RussianWin` afterwards, the value it had before the check. A run that finds the Mac in
use skips the pair and watches only.

`make live-integration-test` stays the full keyboard run (harness window, emitted shifts, clipboard and
input source moved and restored). It takes the focus and the layout of the machine, so it runs on a free
Mac, not during a wave.
