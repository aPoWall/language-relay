## Observation: escape through the driver

`axdrive key --window 9516 --keys esc` posts the key to the process, and the non-activating popover does not
take it, because the panel is not the key window while the user's app stays frontmost. The escape path
itself is covered offscreen (`--ui-self-test`, `closeReasons`) and by hand when the panel is opened from the
menu bar. For stand runs the closing route is `--testbed hide`, which reaches the same `close(reason:)`.

## Live layout switch (wave 9 § D)

`--live-json --seconds N` watches the system input source and prints every switch it saw, with the second it
happened at. It reads only: no window, no key, no layout change, no focus change, so it runs while the Mac
is being worked on.

- run of 4 s at 00:06: 16 samples, start and end `com.apple.keylayout.RussianWin`, 0 switches;
- run of 600 s from 00:03: see `receipts` in the session report; the pair the product declares is
  `com.apple.keylayout.US` and `com.apple.keylayout.RussianWin`.

`make live-integration-test` stays the full keyboard run (harness window, emitted shifts, clipboard and
input source moved and restored). It takes the focus and the layout of the machine, so it runs on a free
Mac, not during a wave.
